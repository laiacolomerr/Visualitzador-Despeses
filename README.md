# Visualitzador de Despeses - Laia Colomer

Aquesta aplicació està dissenyada per guardar i visualitzar les despeses personals.

L'objectiu és portar un control d'aquestes despeses, de manera que es pugui planejar millor l'estalvi, així com les possibles despeses futures.

### Stack tècnic

- Node.js 20
- NPM 10
- Angular 18
- Estils utilitzant SCSS
- Components Standalone

### Estat
Configuració inicial completada i verificada.

## Comandes
### Desenvolupament
Executar en mode desenvolupament
```bash
ng serve
```

Navegar a `http://localhost:4200/`. Quan realitzem canvis a l'aplicació s'aplicaran automàticament al navegador.

### Build
Per generar el build del projecte cal executar:
```bash
ng build
```

Els fitxers es creen al directori `dist/`.

### Tests
Si volem executar els tests utilitzant [Karma](https://karma-runner.github.io) hem d'executar:
```bash
ng test
```
